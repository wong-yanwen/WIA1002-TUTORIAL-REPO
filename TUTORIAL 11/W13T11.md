### Question 1:
What is a binary search tree (BST)?

FIXED ANSWER:

A Binary Search Tree is a binary tree where every node follows an ordering rule.

Left subtree: value are smaller than the node

Right subtree: values are greater than the node

The left and right subtrees must also be BSTs.

Extra note:
- Search, insert and delete depends on the height ,h of the tree.
- Balanced BST: O (log n)
- Skewed BST:O(n)
