1.Explain the problem that occurs when executing the recursive method f(0).

```
public static int f(int n) { 
    if (n == 1) 
        return n; 
    else  
        return n * f(n-1); 
}
```

ANSWER: 

recursive method f(0) will recurse infinitely because 0 multiply by anything will still be zero. It is mathematically impossible for the method to reach the base case.

2.Explain the problem that occurs when executing the recursive method f().
   
```
public static int f(int n) { 
    if (n == 0) 
        return n; 
    else  
        return f(n+1) + n; 
} 
```

ANSWER:

The recursive method will recurse infinitely because there is no maximum value set for n . Thus, if n is positive, n will increase infinitely .
